# Проект

Этот проект представляет собой современную интерпретацию Minecraft на движке Godot. Основные цели проекта — абстрактная простота и высокая производительность. 

## Архитектурные правила
- Основная игровая механика -- алхимия. Алхимия работает по принципу взаимдействия фигур. Если фигура дома пересеклась с фигурой взрыва, то фигура дома должна заменить себя на фиугу разрушеного дома.
- Связь между фигурами через add_owned_shape должна определять зависимую фигуру. Если владеющая фигура при разрушении должна оповестить какую-то фигуру(стена дома должна оповестить дом, если она разршена), то эта фигура называеться зависимой и должна быть внесена в owned фигуры для владеющей.
- Связь между фигурами через add_owned_shape может быть двусторонней и односторонней. Фигура дома должна быть оповещена, если фигуру стены входящей в состав дома разрушели. И наоборот, если фигура дома была разрушена - стена, входящяя в состав дома должна быть оповещена. 
- Список owned определяет направление обхода: уведомления об изменениях и реакции затрагивают только те фигуры, которые явно указаны в списке owned текущей фигуры. Родительская фигура вызывается только в том случае, если она сама указана в списке owned дочерней фигуры.
- propose_shape_change — единственная точка входа для фундаментальной замены (например, когда стена становится разрушеной стеной). Обычные изменения параметров распространяются самой фигурой по списку owned через notify_shape_changed(). 
- Положение фигуры определяется двумя координатами: координатами её октодерева и её собствеными внутри октодерева. Предполагается, что фигуры внутри своего октодерева неподвижны(как дерево неподвижно в координатах планеты), что делает октодерево началом локальной системы отсчёта.
- Если предполагается движение фигуры относительно других систем отсчёта, то необходимо создать ей своё октодерево в on_register() и переопределить у фигуры геттер/сеттер позиции на
```cpp
void set_position(const Vector3& v) {
    if (ShapeSpatialManager* mgr = ShapeSpatialManager::get_singleton()) {
        mgr->set_octree_position(get_id(), v);
    }
}

Vector3 get_position() const {
    if (ShapeSpatialManager* mgr = ShapeSpatialManager::get_singleton()) {
        if (ChunkOctree* octree = mgr->get_octree(get_id())) {
            return octree->get_position();
        }
    }
    return Vector3();
}
```
подобное поведение гарантирует, что положение фигуры будет трактоваться как положение системы отсчёта.

## Правила кода
- Избегайте создания новых полей, классов или функций без явной необходимости.
- Не применяйте явные и заранее не производительные решения, кроме как по явно просьбе.

## Правила построения
- Проект должен быть собран с помощью команды "clear && scons platform=linux debug_symbols=true"
- Код, реализованный в соответствии с задачей, и сборка, выполненная без ошибок, считается выполненной задачей.
- Запуск проекта Godot возможен только в том случае, если требуется отладка, и только в headless only режиме.
